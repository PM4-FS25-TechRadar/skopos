Definition of Done (DoD)
Die Definition of Done legt die gemeinsamen Qualitätsstandards und Abnahmekriterien fest, die erfüllt sein müssen, damit eine User Story, ein Task oder ein Produktinkrement als abgeschlossen gilt. Sie schafft ein einheitliches Verständnis im Team und stellt sicher, dass das Arbeitsergebnis vollständig und einsatzbereit ist.



Ein Arbeitsergebnis gilt als "Done", wenn:
* Die Akzeptanzkriterien der User Story sind vollständig erfüllt
* Die Implementierung ist abgeschlossen, fehlerfrei und funktionsfähig
* Es wurden automatisierte Unit Tests geschrieben und erfolgreich ausgeführt
* Ein Code Review wurde durchgeführt und freigegeben
* Der Code ist in den Hauptentwicklungszweig integriert
* Das Build läuft ohne Fehler
* Es bestehen keine offenen Fehler im Zusammenhang mit der Umsetzung
* Die Lösung entspricht den vereinbarten UI/UX-Richtlinien (sofern relevant)
* Notwendige Integrationstests wurden durchgeführt und bestanden
* Die technische Dokumentation wurde aktualisiert
* Die Funktionalität wurde vom Product Owner abgenommen (sofern erforderlich)
* Die Änderungen wurden erfolgreich in eine geeignete Test- oder Produktionsumgebung deployed (je nach Projektphase)
